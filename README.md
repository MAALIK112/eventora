# Eventora

## Overview
Eventora is a modern event booking and service marketplace app designed to help users discover, compare, and book event-related services in one place. It brings together service discovery, booking, payments, profile management, and support within a clean mobile-first experience.

## Problem Statement
Planning an event often involves searching across multiple platforms, comparing vendors, keeping track of bookings, and managing payments manually. This creates confusion, delays, and extra effort for users trying to organize important events such as weddings, birthdays, corporate functions, and celebrations.

Eventora solves this by providing a single app where users can find trusted event services, evaluate options, confirm bookings, and manage the entire process in one place.

## What the App Does

### 1. Browse Event Services
Users can explore services across categories such as:
- Photography
- Catering
- Event planning
- Venues
- Decorations
- Entertainment
- Other event support services

### 2. Search and Filter
The app allows users to quickly find suitable services using search and filtering options based on:
- category
- pricing
- popularity
- ratings
- service availability

### 3. View Service Details
Each service includes relevant details such as:
- name and description
- pricing and packages
- ratings and reviews
- provider information
- availability and booking information

### 4. Book Services
Users can proceed through a booking flow to:
- select a service
- choose a package or option
- review the booking details
- confirm the reservation
- receive a confirmation status

### 5. Manage Bookings
The app includes booking management features for:
- upcoming reservations
- previous bookings
- status tracking
- booking detail review

### 6. Payments and Wallet
Eventora includes wallet and payment features such as:
- wallet top-up
- payment method selection
- transaction history
- pricing breakdown
- order confirmation

### 7. Profile and Account Management
Users can:
- create an account or log in
- edit profile information
- manage settings
- personalize their experience

### 8. Support
The app includes a support section to help users:
- access help
- resolve issues
- contact assistance when needed

## Key Features

- Search and filtering
- Service detail pages

- Payment and wallet management

## Target Users

Eventora simplifies event planning by helping users discover the right providers, compare options, complete bookings, and manage payments and reservations from a single app.
